## 新 Playbook 提取流程

完成一个功能开发后，如果满足以下**任一条件**，应提取 playbook：

1. 过程中踩了 **≥2 个非平凡坑**（不是 typo、配置遗漏级别）
2. 发现了**可复用的通用模式**（其他功能也会遇到）
3. 排查过程耗时 **>30 分钟**
4. 最终方案与初始方案**有显著差异**（走了弯路）

提取步骤：
1. 复制 `.harness/templates/playbook-template.md` 到 `.harness/playbooks/{topic}.md`
2. 按模板填写每个问题的现象→根因→处理办法→复用建议
3. 在本文件（`index.md`）的索引表和场景映射表中添加条目
4. 如果提取出跨场景通用原则，添加到"通用原则速查"表中
